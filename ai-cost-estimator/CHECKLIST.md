## الف) خطاهای قطعی و باگ‌های منطقی کد
- [x] **`app.js` → تابع `syncModelsData()`**: اتصال به منبع داده ساختاریافته واقعی (`prices.json`) و بازخوانی زنده نسخه و تاریخ مستندات.
- [x] **`app.js` → تابع `handleLiveRateRequest()`**: اصلاح پیام در زمان خطا/آفلاین (نمایش صریح عدم موفقیت استعلام آنلاین و فعال بودن نرخ دستی بازار با نشانگر هشدار).
- [x] **تطبیق API نوبیتکس**: استفاده از `lastTradePrice / 10` به همراه سیگنال انصراف در صورت کندی (Timeout 4s) و سازگاری با محیط‌های مختلف.
- [x] **`table-renderer.js` → تابع `renderRecommendations()`**: اضافه کردن شرط ایمنی قبل از اجرا برای جلوگیری کامل از خطای `undefined` در صورت خالی بودن لیست ارزیابی‌شده.
- [x] **کارت بهترین گزینه رایگان در فیلترها**: عدم نمایش مدل‌های پولی در کارت رایگان؛ در صورت نبود گزینه رایگان، نمایش کارت شفاف عدم وجود پلن رایگان.
- [x] **اصلاح منطق فیلتر رایگان**: تعریف و اعمال فیلد `hasFreeTier: true` به مدل‌هایی با سهمیه رایگان پایدار (مانند Gemini در AI Studio و DeepSeek در وب).
- [x] **پویایی تاریخ همگام‌سازی**: اتصال نشانگر `#sync-status-badge` به فیلد واقعی `lastVerifiedFa` در دیتاست اصلی.
- [x] **هماهنگی شناسه و نام**: اصلاح `id: 'gpt-4o'` با نام رسمی `OpenAI GPT-4o`.

## ب) بازنویسی موتور محاسباتی (`calculator.js`)
- [x] **محاسبه مبتنی بر فرمول توکن:** محاسبه ریاضی هزینه بر اساس `(Input Tokens * Input Rate) + (Output Tokens * Output Rate)` برای تمام مدل‌های متنی و کدنویسی.
- [x] **ضرایب پویا به تفکیک مدل:** تعریف نرخ واقعی رزولوشن‌ها برای هر مدل (مانند تعرفه اختصاصی HD در DALL-E 3 و 4K در Nano Banana).
- [x] **تفکیک API مصرفی از اشتراک ماهانه در بخش کد:** جداسازی کامل مدل‌های توکنی از ابزارهای IDE با اشتراک ثابت ماهیانه (Cursor, v0, Bolt).
- [x] **ورودی تعاملی میانگین توکن در چت:** افزودن منوی انتخابی عمق تعامل (کوتاه، استاندارد، طولانی) و محاسبه زنده توکن‌ها.
- [x] **بهینه‌سازی تابع `formatCurrencyFa`:** حذف شرط‌های تکراری و ساده‌سازی فرمت‌بندی تومان.

## ج) تطبیق نسخه‌ها و تعرفه‌ها با استانداردهای رسمی ۲۰۲۶
- [x] **Midjourney:** ارتقا به نسخه فعلی **V8.2** و تطبیق پلن‌های Basic ($10), Standard ($30), Pro ($60), Mega ($120).
- [x] **DeepSeek:** به‌روزرسانی به نسخه رسمی **V4-Pro (0813)** با نرخ ساعات اوج ($1.32 In / $3.96 Out) و غیراوج ($0.66 In / $1.98 Out).
- [x] **OpenAI Sora:** ثبت وضعیت رسمی ادغام درون ChatGPT Plus/Pro و بازنشستگی اپلیکیشن مجزا.
- [x] **تطبیق مدل‌های DALL-E و GPT:** اصلاح نام‌گذاری‌ها به نسخه‌های رسمی اعلامی OpenAI (DALL-E 3 و GPT-4o).
- [x] **تطبیق تعرفه‌های Claude (Anthropic):** به‌روزرسانی تعرفه‌های رسمی Claude 3.7 Sonnet و Claude 3.5 Haiku.
- [x] **سایر مدل‌ها:** اعتبارسنجی دقیق قیمت‌های Seedance 2.5، Nano Banana Pro، FLUX 1.1 و Kling 2.0 با صفحات مستندات رسمی.
