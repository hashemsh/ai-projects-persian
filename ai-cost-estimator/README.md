# 💰 محاسبه‌گر و مقایسه‌گر هوشمند هزینه مدل‌های هوش مصنوعی (AI Cost Estimator)

ابزار تخصصی و بلادرنگ برای برآورد، مقایسه و تحلیل هزینه‌های مدل‌های مختلف هوش مصنوعی در ۴ زمینه اصلی:
1. **تولید تصویر (Image Generation):** Midjourney v6.1، FLUX.1 (Schnell/Dev/Pro)، DALL-E 3، Stable Diffusion 3.5، Ideogram 2.0، Imagen 3
2. **تولید ویدیو (Video Generation):** Seedance 2.5 (ByteDance با صداگذاری محلی و رقص)، Runway Gen-4 / Turbo، Luma Ray 2، Kling AI 2.0، Sora Pro
3. **توسعه نرم‌افزار، وبسایت و کدنویسی (Code, Web & App Development):** Claude 3.5 Sonnet، DeepSeek V3/Coder، GPT-4o، Gemini 1.5 Pro، Cursor Pro، v0 by Vercel، Bolt.new
4. **چت، خلاصه و دستیار متنی ساده (Chat, Text & Reasoning):** DeepSeek-R1 / V3، GPT-4o mini، Claude 3.5 Haiku، Gemini 1.5 Flash، Llama 3.3 70B

## 🌟 قابلیت‌های کلیدی
- **نمایش دوگانه ارزی:** محاسبه دلاری دقیق به همراه تبدیل آنی به تومان با نرخ روز قابل شخصی‌سازی
- **پیشنهاد هوشمند مدل:** نشان‌گذاری برترین مدل بازار (Best Quality)، بهترین ارزش خرید (Best Value) و بهترین گزینه رایگان (Free Alternative)
- **لوگوهای بهینه‌شده WebP:** لوگوی رسمی شرکت‌ها و مدل‌های مطرح
- **معماری ماژولار و سازگار با وب تمیز:** رعایت کامل سقف ۲۰۰ خطی فایل‌ها، پشتیبانی کامل از `file://` و GitHub Pages
