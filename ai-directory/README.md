# دایرکتوری و راهنمای جامع مدل‌های هوش مصنوعی (AI Models & Tools Directory)

یک ابزار جامع، سریع، مدرن و ۱۰۰٪ کلاینت‌ساید برای جستجو، مقایسه و شناخت کاربرد بیش از ۵۰ مدل و سرویس پیشرو هوش مصنوعی جهان با پشتیبانی کامل از زبان فارسی و تایپوگرافی وزیرمتن.

---

## ✨ ویژگی‌های کلیدی

- **بانک اطلاعاتی جامع بیش از ۵۰ ابزار و مدل هوش مصنوعی:** پوشش تمام مدل‌های مطرح دنیا شامل OpenAI (GPT-4o, o1)، Google (Gemini 2.0, NotebookLM)، Anthropic (Claude 3.5 Sonnet)، DeepSeek (V3, R1)، Meta Llama 3.3، Midjourney، Flux.1، Runway، Suno، ElevenLabs، Cursor، v0.dev، Bolt.new و ده‌ها ابزار دیگر.
- **جدول ۴ ستونه استاندارد با چیدمان اختصاصی:**
  1. **لوگو:** نمایش وکتور اختصاصی SVG هر سرویس با رزولوشن بی‌نقص.
  2. **نام و کمپانی سازنده:** همراه با برچسب‌های وضعیت دسترسی (رایگان، متن‌باز، اشتراکی).
  3. **آدرس وب‌سایت:** لینک مستقیم خارجی همراه با دکمه کپی فوری آدرس در کلیپ‌بورد.
  4. **عملکرد و کاربرد به زبان ساده و روان:** شامل کاربرد اصلی، تشریح قابلیت‌ها و تگ‌های کلیدی.
- **موتور جستجوی آنی و هوشمند (Live Search):** فیلتر لحظه‌ای بر اساس نام مدل، کمپانی، کاربرد (کدنویسی، تصویرسازی، استدلال، آهنگسازی...) با نرمال‌سازی خودکار حروف فارسی و انگلیسی.
- **فیلترهای موضوعی دسته‌بندی‌شده:** دسترسی با ۱ کلیک به دسته‌های چت و استدلال، کدنویسی، ساخت نرم‌افزار، تولید تصویر، ویدیو، صدا و موسیقی، پژوهش و مدل‌های متن‌باز.
- **نمای دوگانه ریسپانسیو (Dual Layout):** جدول شیشه‌ای مدرن در دسکتاپ و کارت‌های بهینه‌سازی‌شده در موبایل و تبلت بدون اسکرول افقی ناخواسته.
- **دانشنامه آموزشی بنتو در انتهای صفحه:** کادر مستقل راهنمای انتخاب هوش مصنوعی با دیاگرام تصمیم‌گیری و ۴ کارت بنتو با ساختار متقارن ۲ ستون در ۲ ردیف (2x2).

## 🛠️ ساختار فنی و ماژولار

```text
ai-directory/
├── index.html                           # ساختار معنایی HTML5 استاندارد
├── README.md                            # مستندات فنی ابزار
└── assets/
    ├── css/
    │   └── style.css                    # استایل‌های اختصاصی و گلس‌مورفیسم
    └── js/
        ├── data/
        │   └── ai-models-data.js        # بانک اطلاعاتی بیش از ۵۰ مدل همراه با وکتور لوگوها
        └── app.js                       # موتور فیلتر، جستجوی بلادرنگ و تعاملات UI
```

## 🚀 نحوه اجرا و استفاده محلی

این پروژه کاملاً کلاینت‌ساید بوده و بدون نیاز به هیچ وابستگی خارجی یا فریم‌ورک‌های سنگین اجرا می‌شود:

```bash
# اجرای سرور محلی
python -m http.server 8080

# باز کردن در مرورگر
http://localhost:8080/ai-directory/
```

همچنین فایل `index.html` به صورت مستقیم با پروتکل محلی `file:///` نیز قابل باز شدن و استفاده است.
