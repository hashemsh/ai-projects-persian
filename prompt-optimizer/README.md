# ⚡ استودیو مهندسی پرامپت هوش مصنوعی (Prompt+)
> ابزار تخصصی و مدرن مهندسی پرامپت فارسی برای تبدیل دستورات عامیانه و معمولی به پرامپت‌های سطح اول جهانی برای مدل‌های زبانی بزرگ (LLMs).

🔗 **مشاهده دموی زنده:** [hashemsh.github.io/ai-projects-persian/prompt-optimizer/](https://hashemsh.github.io/ai-projects-persian/prompt-optimizer/)

## 🌟 قابلیت‌ها و امکانات کلیدی (Key Features)

### ۱. مهندسی خودکار و چندلایه پرامپت
- **تزریق چارچوب RTFC:** تفکیک هویت تخصصی (`Role`)، شرح دقیق وظیفه (`Task`)، فرمت خروجی مطلوب (`Format`) و خط‌قرمزهای اجرایی (`Constraints`).
- **ترفند طلایی دوزبانه (Bilingual Trick):** بازنویسی خودکار درخواست و دستورات به زبان انگلیسی تخصصی و الزام مدل به ارائه پاسخ عمیق به زبان فارسی سلیس (افزایش ۳۰ تا ۵۰ درصدی دقت فنی مدل‌های OpenAI و Anthropic).
- **استدلال زنجیره‌ای (Chain-of-Thought - CoT):** وادار کردن مدل به تفکیک مسئله و استدلال گام‌به‌گام قبل از تولید کد یا نتیجه نهایی.

### ۲. استخراج هوشمند قیود منفی (Negative Constraints)
- تشخیص خودکار عبارات محاوره‌ای نظیر *«بدون مقدمه‌چینی»*، *«سنگین نباشه»* یا *«کد کل پروژه بدون جای خالی»* و تبدیل آن‌ها به قوانین سفت‌وسخت مهندسی:
  - `No conversational preamble, greetings, or introductory filler.`
  - `Provide complete, self-contained, and runnable source code without placeholders.`
  - `Keep the solution clean, lightweight, and performant without unnecessary bloat.`

### ۳. سنجش زنده عیار و کیفیت پرامپت (Prompt Auditor)
- امتیازدهی بلادرنگ از ۰ تا ۱۰۰ بر اساس استانداردهای پرامپتینگ.
- چک‌لیست ۴ معیاره: تعیین نقش، شفافیت وظیفه، قالب خروجی و قیود منفی.
- ارائه توصیه‌های آنی برای تکمیل کاستی‌های متن ورودی.

### ۴. بانک ۱۰ الگوی آماده حرفه‌ای (Presets Library)
قالب‌های از پیش‌آماده برای حوزه‌های پرتکرار وب:
1. **برنامه‌نویسی:** بازبینی کد، امنیت و ریفکتورینگ (`Code Review`)
2. **فول‌استک:** معماری دیتابیس، اندپوینت‌های RESTful و کامپوننت فرانت‌اند
3. **کپی‌رایتینگ:** تیتر و لندینگ پیج با روانشناسی AIDA و نرخ تبدیل بالا
4. **سئو و وبلاگ:** استراتژی مقاله پیلار، کلاستر محتوایی و کیوردهای LSI
5. **سئو تکنیکال:** تولید اسکیما مارک‌آپ FAQ استاندارد گوگل با فرمت JSON-LD
6. **فروش B2B:** ایمیل مارکتینگ سازمانی با نرخ پاسخ بالا برای مدیران ارشد
7. **طراحی محصول:** ارزیابی هیوریستیک تجربه کاربری (UX Audit)
8. **تصویرسازی:** پرامپت عکاسی و رندر سینمایی ۸K میدجورنی
9. **کسب‌وکار:** تحلیل جامع ماتریس SWOT و راهکارهای اجرایی خنثی‌کننده
10. **پژوهش و تحلیل:** استخراج متدولوژی، فرضیات و یافته‌های مقاله علمی

### ۵. ابزارهای بهره‌وری و پرش مستقیم
- **🤖 باز کردن در ChatGPT:** کپی فوری متن و باز کردن پرامپت در ChatGPT.
- **🧠 باز کردن در Claude:** کپی فوری متن و باز کردن مستقیم در Anthropic Claude.
- **📥 خروجی Markdown (.md):** دانلود فایل پرامپت جهت استفاده در پروژه‌ها و گیت.
- **⚖️ مقایسه‌گر قبل و بعد (Diff View):** مقایسه دو کادره درخواست خام در برابر پرامپت بهینه‌شده.
- **💡 تقلب‌نامه ترفندهای مهندسی پرامپت:** راهنمای تکنیک‌های Few-Shot، پرسوناسازی و تگ‌های معنایی XML.

## 🏛️ معماری ماژولار و پاک (Clean Modular Web)
پروژه با سخت‌گیرانه‌ترین استانداردهای معماری وب مدرن و با **سقف حداکثر ۲۰۰ خط برای تک‌تک فایل‌ها** پیاده‌سازی شده است:

```plaintext
prompt-optimizer/
├── index.html                      # مارک‌آپ سمانتیک بدون هیچ‌گونه استایل یا اسکریپت اینلاین
├── README.md                       # مستندات پروژه
└── assets/
    ├── images/
    │   └── prompt-engineering-banner.jpg
    ├── css/
    │   ├── style.css               # استایل‌های شیشه‌ای و انیمیشن‌ها
    │   ├── variables.css           # پالت تیره و متغیرهای رنگی
    │   ├── base.css                # ریست و تایپوگرافی
    │   └── layout.css              # گرید و لایه‌بندی واکنش‌گرا
    └── js/
        ├── data.js                 # داده‌های نقش‌ها، مدل‌ها و ۱۰ الگوی آماده
        ├── guide-data.js           # داده‌های تقلب‌نامه ترفندها و متغیرها
        ├── translator.js           # موتور ترجمه و استخراج قیود منفی
        ├── scorer.js               # تحلیل‌گر و محاسبه‌گر عیار پرامپت
        ├── generator.js            # کامپایلر فریم‌ورک‌های استاندارد
        ├── export-ui.js            # هندلرهای دانلود، چت‌بات‌ها و مقایسه‌گر
        └── app.js                  # کنترلر اصلی رویدادها و اینترفیس
```

- **سازگاری کامل با اجرای آفلاین (`file:///`):** تمام ماژول‌ها بدون باگ CORS با دابل‌کلیک اجرا می‌شوند.
