# 📱 استودیو و ژنراتور کیوآرکد پیشرفته (QR Code Studio Pro)

یک ابزار کلاینت‌ساید، مدرن و فوق‌العاده کاربردی برای ساخت، طراحی بصری و شخصی‌سازی انواع کدهای QR بر اساس استانداردهای بین‌المللی ISO/IEC.

---

## ✨ قابلیت‌ها و ویژگی‌های کلیدی

1. **پشتیبانی از فرمت‌های کاربردی و استاندارد:**
   - 🔗 **لینک و وب‌سایت (URL):** هدایت خودکار مرورگر گوشی به آدرس وب با پیشوند امن `https://`.
   - 📶 **اتصال سریع به وای‌فای (Wi-Fi):** پروتکل استاندارد `WIFI:T:...` جهت اتصال آنی بدون نیاز به تایپ دستی رمز عبور.
   - 💬 **واتساپ با متن پیام آماده (WhatsApp):** تبدیل شماره به استاندارد بین‌المللی و بازکردن خودکار چت همراه با پیام پیش‌نویس.
   - ✈️ **کانال، گروه و چت تلگرام (Telegram):** هدایت مستقیم به آیدی تلگرام یا اشتراک‌گذاری پست.
   - 📸 **پیج اینستاگرام (Instagram):** انتقال کاربر به صفحه رسمی یا پست‌های اینستاگرام.

2. **طراحی بصری و شخصی‌سازی استایل:**
   - **الگوهای نقاط (Dots Pattern):** ۶ استایل متنوع (Rounded، Dots، Classy، Classy Rounded، Square و Extra Rounded).
   - **فریم چشم‌های گوشه (Corner Square & Dot):** فریم‌های خمیده، دایره‌ای یا مربعی.
   - **پالت رنگ و گرادینت:** پشتیبانی از گرادینت‌های دو رنگ خطی و شعاعی، رنگ پس‌زمینه دلخواه و پس‌زمینه شفاف (Transparent).
   - **لوگوی اختصاصی در مرکز:** شامل آیکون‌های وکتور شبکه‌های اجتماعی (اینستاگرام، تلگرام، واتساپ)، نمادهای بانکی و وای‌فای، به همراه آپلود عکس و لوگوی شخصی.

3. **خروجی باکیفیت و تست اسکن:**
   - دانلود **PNG** با کیفیت بالا (1200 پیکسل).
   - دانلود **SVG** وکتور برداری مناسب برای چاپ افست، کاتالوگ و بیلبورد بدون افت کیفیت.
   - دانلود **WebP** کم‌حجم برای طراحان وب.
   - کپی مستقیم تصویر در کلیپ‌بورد سیستم (`ClipboardItem`).
   - شبیه‌ساز تست اسکن دوربین با موتور **jsQR** درون مرورگر جهت راستی‌آزمایی پیش از چاپ.

4. **امنیت و حفظ حریم خصوصی:**
   - ۱۰۰٪ کلاینت‌ساید (Client-Side)؛ تمامی کیوآرکدها در مرورگر کاربر رندر شده و هیچ دیتایی به هیچ سروری ارسال نمی‌شود.

## 🛠️ ساختار فایل‌ها

```text
qr-studio/
├── index.html                      # رابط کاربری استودیو
├── README.md                       # مستندات پروژه
├── assets/
│   ├── css/
│   │   └── style.css               # استایل‌های دارک گلس‌مورفیک و فونت وزیرمتن
│   ├── js/
│   │   ├── vendor/                 # کتابخانه‌های استاندارد محلی
│   │   │   ├── qr-code-styling.js  # موتور رندر کیوآرکد
│   │   │   └── jsqr.min.js         # رمزگشای تست اسکن
│   │   ├── data/
│   │   │   └── presets.js          # پالت‌های رنگی و آیکون‌های برندها
│   │   ├── engine/
│   │   │   ├── qr-payload.js       # فرمت‌کننده پروتکل‌های دیتای استاندارد
│   │   │   └── qr-renderer.js      # کنترلر رندر و اکسپورت
│   │   └── ui/
│   │       ├── form-templates.js   # تمپلیت‌های فرم ورودی
│   │       ├── form-handlers.js    # بایندر داده‌های فرم
│   │       ├── palette-picker.js   # انتخابگر رنگ، لوگو و توست
│   │       └── app.js              # هماهنگ‌کننده اصلی رویدادها
│   └── images/
```
