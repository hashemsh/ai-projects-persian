# سازنده و تحلیل‌گر عبارات منظم (Regex AI Studio)

یک میکرواپ مدرن و ۱۰۰٪ کلاینت‌ساید برای ساخت، تست زنده، اعتبارسنجی بلادرنگ و تشریح مرحله‌به‌مرحله الگوهای عبارات منظم (Regular Expressions) به زبان فارسی، همراه با پریست‌های بومی ایران، تبدیل زبان طبیعی به Regex و تولید خودکار کد برای ۸ زبان برنامه‌نویسی.

---

## 🌟 ویژگی‌های کلیدی

1. **تست و اعتبارسنجی زنده (Live Match Highlighter):**
   - هایلایت رنگی زنده تطابق‌ها در متن آزمایشی با نمایش تعداد تطابق‌ها و زمان اجرا به میلی‌ثانیه.
   - پشتیبانی از ۵ پرچم حیاتی: `g` (سراسری)، `i` (حساس نبودن به حروف بزرگ/کوچک)، `m` (چندخطی)، `s` (دات تمام)، `u` (پشتیبانی کامل از یونیکد و متون فارسی).
2. **تشریح گام‌به‌گام الگو (Visual Explainer & Breakdown):**
   - تفکیک خودکار کاراکترها و توکن‌های رجکس (لنگرها، کوانتیفایرها، کلاس‌های کاراکتر، گروه‌ها) و ارائه توضیحات شفاف و فارسی برای هر بخش.
3. **مبدل زبان طبیعی به Regex (AI Prompt Engine):**
   - تبدیل دستورات محاوره‌ای فارسی (مانند «شماره موبایل ایران»، «کد ملی»، «آدرس سایت»، «ایمیل معتبر») به الگوهای دقیق رجکس.
4. **پریست‌های آماده و استاندارد بومی ایران و وب:**
   - شماره موبایل ایران، کد ملی ۱۰ رقمی، کد پستی ۱۰ رقمی، کارت بانکی ۱۶ رقمی شتاب، تاریخ شمسی، کد رنگ هگزادسیمال، تگ‌های HTML، آدرس IPv4 و رمز عبور قوی.
5. **مولد کد آماده برای ۸ زبان برنامه‌نویسی:**
   - JavaScript / Node.js, TypeScript, Python 3, PHP (PCRE), C# (.NET), Java, Go, C++.
6. **ابزار جایگزینی زنده متنی (Regex Replace Tool):**
   - پیش‌نمایش درلحظه رشته جایگزین با پشتیبانی از ارجاعات گروهی (`$1`, `$2`).
7. **راهنمای جامع آموزشی و چیت‌شیت کاراکترها:**
   - نمودار وکتور آناتومی رجکس، جدول تفکیک‌شده لنگرها، کوانتیفایرها و نکات سئو و یونیکد فارسی.

## 📂 معماری ماژولار پروژه

مطابق با استاندارد **Clean Modular Web**:
- صفر خط استایل یا اسکریپت درون فایل HTML.
- رعایت سقف سخت‌گیرانه زیر ۲۰۰ خط برای تک‌تک فایل‌های منبع.
- استفاده از مسیرهای نسبی (`./assets/...` و `../assets/...`) جهت سازگاری کامل با GitHub Pages و اجرای مستقیم لوکال (`file:///`).

```text
regex-studio/
├── index.html                  # مارک‌آپ تمیز و معنایی (زیر ۲۰۰ خط)
├── README.md                   # مستندات کامل پروژه
├── assets/
│   ├── css/
│   │   ├── style.css           # استایل اصلی و تم‌ها
│   │   └── components/
│   │       ├── editor.css      # هایلایتر زنده و دکمه‌های کنترل
│   │       └── cheatsheet.css  # جدول چیت‌شیت و کارت‌های راهنما
│   ├── js/
│   │   ├── app.js              # بوت‌استرپر اصلی برنامه
│   │   ├── data/
│   │   │   ├── presets.js      # کتابخانه پریست‌های بومی و وب
│   │   │   ├── nlp-rules.js    # موتور تبدیل زبان طبیعی به Regex
│   │   │   └── cheatsheet-data.js # دیتای چیت‌شیت فارسی
│   │   ├── engine/
│   │   │   ├── regex-matcher.js   # موتور تست و اجرای تطابق
│   │   │   ├── regex-explainer.js # موتور تشریح ساختار الگو
│   │   │   └── code-generator.js  # مولد کد ۸ زبان
│   │   └── ui/
│   │       ├── live-editor.js     # کنترلر رابط کاربری تعاملی
│   │       ├── presets-ui.js      # فیلتر و تراشه‌های پریست‌ها
│   │       └── code-modal.js      # مودال خروجی کدهای برنامه‌نویسی
│   └── images/
│       ├── banner.svg          # بنر گرافیکی وکتور
│       └── regex-anatomy.svg   # اینفوگرافیک آناتومی Regex
```
