# 🎯 یو‌تی‌ام بیلدر پرو (UTM Builder Pro)

> ابزار پیشرفته، استاندارد و جامع ساخت، اعتبارسنجی و مدیریت لینک‌های کمپین بازاریابی برای Google Analytics 4 با پریست‌های اختصاصی ادنتورک‌های ایرانی، ساخت بارکد QR و تولید گروهی لینک‌ها.

🔗 **دموی آنلاین:** [hashemsh.github.io/ai-projects-persian/utm-builder/](https://hashemsh.github.io/ai-projects-persian/utm-builder/)

---

## ✨ قابلیت‌ها و ویژگی‌های کلیدی

1. **پریست‌های آماده شبکه‌های تبلیغاتی ایرانی و بین‌المللی:**
   - تنظیم خودکار با یک کلیک برای **یکتانت (Yektanet)**، **مدیااد (Mediaad)**، **تپسل (Tapsell)**، **اینستاگرام (Story & Bio)**، **کانال تلگرام**، **گوگل ادز (Google Ads)**، **پیامک متنی (SMS)** و **خبرنامه ایمیلی**.
2. **شبیه‌ساز زنده گزارش‌های Google Analytics 4 (GA4):**
   - پیش‌نمایش دقیق نحوه ثبت ترافیک در ابعاد `Session default channel group`، `Session source / medium` و `Session campaign` پیش از اجرای کمپین.
3. **تولیدکننده بارکد وکتور QR Code (۱۰۰٪ کلاینت‌ساید):**
   - تولید لحظه‌ای فایل‌های وکتور استاندارد SVG برای چاپ در بروشور، بیلبورد و بسته‌بندی محصولات فیزیکی بدون نیاز به APIهای خارجی یا ارسال دیتا به سرور.
4. **تولید گروهی لینک‌های کمپین (Batch Matrix Generator):**
   - ساخت همزمان یک کمپین برای تمامی کانال‌ها و استخراج مستقیم فایل آماده اکسل/CSV.
5. **اعتبارسنجی و ارزیابی استاندارد (UTM Quality Audit):**
   - تحلیل بلادرنگ حروف کوچک (Lowercase)، تبدیل فواصل به خط تیره (-) یا آندرلاین (_) و سنجش کامل بودن پارامترها.
6. **ذخیره‌سازی و تاریخچه محلی (LocalStorage):**
   - بازیابی آخرین ورودی‌های کاربر و ذخیره خودکار سابقه کمپین‌های ساخته‌شده.

## 🛠️ ساختار ماژولار پروژه

```plaintext
utm-builder/
├── index.html                   # هسته نشانه گذاری معنایی (زیر ۱۸۰ خط)
├── README.md                    # مستندات تخصصی ابزار
└── assets/
    ├── css/
    │   ├── variables.css        # متغیرهای رنگی و تم
    │   ├── style.css            # استایل اصلی هاب
    │   └── components/          # کامپوننت‌های شیشه‌ای، فرم و مدال
    └── js/
        ├── data/                # پریست‌ها و متغیرهای کمپین
        ├── engine/              # اعتبارسنجی URL، موتور QR و Batch
        ├── ui/                  # کنترلر فرم، شبیه‌ساز GA4 و اکسپورت
        └── app.js               # هدایت‌کننده ماژول‌ها (Orchestrator)
```
