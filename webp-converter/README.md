# مبدل و فشرده‌ساز تصاویر به WebP (WebP Studio Pro)

یک ابزار مدرن، ۱۰۰٪ کلاینت‌ساید و کاملاً محرمانه جهت تبدیل و فشرده‌سازی آنلاین انواع فرمت‌های تصویری (PNG, JPG, JPEG, GIF, SVG, BMP) به فرمت بهینه‌شده نسل بعدی **WebP** بر پایه Canvas API بدون ارسال حتی یک بایت داده به هیچ سروری.

---

## 🌟 ویژگی‌های کلیدی

1. **پردازش ۱۰۰٪ محلی و کلاینت‌ساید (Client-Side & Confidential):**
   - تمامی مراحل خواندن فایل، رندرینگ، تغییر ابعاد و فشرده‌سازی درون پردازنده مرورگر کاربر انجام می‌شود؛ بدون نیاز به بک‌اند یا آپلود اینترنتی.
2. **کاهش چشمگیر حجم فایل (تا ۸۵٪ صرفه‌جویی):**
   - صرفه‌جویی قابل توجه در پهنای باند و سرعت بارگذاری با حفظ شفافیت کانال آلفا و بالاترین کیفیت بصری.
3. **اسلایدر کیفیت هوشمند (Lossy & Lossless Quality Control):**
   - امکان تنظیم ضریب کیفیت فشرده‌سازی از ۱۰٪ تا ۱۰۰٪ با مقدار بهینه پیشنهادی ۸۰٪ برای صفحات وب.
4. **تغییر ابعاد تصویر (Image Resizing):**
   - پریست‌های مقیاس‌بندی ۲۵٪، ۵۰٪، ۷۵٪ و ۱۰۰٪ با حفظ دقیق نسبت ابعاد (Aspect Ratio).
5. **تبدیل تکی و دسته‌ای (Batch Conversion):**
   - پشتیبانی از درگ و دراپ همزمان چندین فایل تصویری و پیش‌نمایش کارت‌ها با دکمه دانلود تکی و دانلود گروهی.
6. **مقایسه بلادرنگ قبل و بعد:**
   - نمایش حجم اولیه، حجم WebP تولیدشده، درصد کاهش حجم و ابعاد خروجی به پیکسل.
7. **راهنمای جامع و اینفوگرافیک مقایسه‌ای:**
   - نمودار وکتور مقایسه WebP با PNG و JPEG، پشتیبانی مرورگرها و فاکتورهای بهینه‌سازی سرعت LCP در Core Web Vitals.

## 📂 ساختار فایل‌های ماژولار

مطابق با استاندارد **Clean Modular Web**:
- صفر خط استایل یا اسکریپت درون فایل HTML.
- رعایت سقف سخت‌گیرانه زیر ۲۰۰ خط برای تک‌تک فایل‌های منبع.
- استفاده از مسیرهای نسبی (`./assets/...` و `../assets/...`) جهت سازگاری کامل با GitHub Pages و اجرای مستقیم لوکال (`file:///`).

```text
webp-converter/
├── index.html                  # مارک‌آپ معنایی و ساختار تمیز (زیر ۲۰۰ خط)
├── README.md                   # مستندات کامل پروژه
├── assets/
│   ├── css/
│   │   ├── style.css           # استایل اصلی و ایمپورت‌ها
│   │   └── components/
│   │       ├── dropzone.css    # استایل دراپ‌زون و اسلایدرها
│   │       └── preview.css     # استایل کارت‌ها و گالری
│   ├── js/
│   │   ├── app.js              # بوت‌استرپر هماهنگ‌کننده
│   │   ├── engine/
│   │   │   ├── format-utils.js # فرمت‌کننده‌ها و سازنده نمونه تست
│   │   │   └── image-processor.js # موتور فشرده‌سازی Canvas و Blob
│   │   └── ui/
│   │       ├── dropzone-ui.js  # کنترلر درگ و دراپ و اسلایدر
│   │       └── gallery-ui.js   # رندرینگ کارت‌ها و دانلود گروهی
│   └── images/
│       ├── banner.svg          # بنر گرافیکی وکتور
│       └── webp-comparison.svg # اینفوگرافیک مقایسه وب‌پی با رقبا
```
